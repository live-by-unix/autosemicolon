Built for your flow

Less punctuation. More programming.

Auto stays out of your way and only acts when its statement analysis is confident enough.

⌁

Automatic insertion

Detects likely statement endings as you type and when you move to a new line. No special key or command required.

⌘

Language-aware

Uses language-specific handling to avoid common false positives around declarations, control structures, comments, and incomplete code.

◉

Confidence-based

Choose Conservative or Balanced behavior. Favor fewer incorrect insertions or allow more situations to be handled automatically.

⚙

Configurable

Enable or disable individual languages, choose insertion triggers, and inspect status or diagnostic output.

⌁

Offline by design

Runs locally without AI inference, API keys, external services, or network requests during editing.

◇

Privacy-focused

No telemetry or analytics. Your source code stays on your computer while Auto does its work.

Make it yours

Simple settings. Your rules.

Configure Auto from VS Code Settings (Ctrl+, or Cmd+,) or edit your settings.json.

Core settings

auto.enabled

Boolean · Default: true
Master switch for Auto.

auto.enabledLanguages

String array · Default: []
Limit Auto to specific language identifiers. Empty means all supported languages are eligible.

auto.disabledLanguages

String array · Default: []
Explicitly exclude languages such as JavaScript or TypeScript.

auto.confidenceMode

"conservative" (default) or "balanced".

Insertion & diagnostics

auto.insertOnNewline

Boolean · Default: true
Insert when a completed statement is finalized by moving to a new line.

auto.insertOnClosingDelimiter

Boolean · Default: false
Try detecting completed statements after relevant closing delimiters.

auto.debugLogging

Boolean · Default: false
Show detailed diagnostics in the Output channel.

{"auto.confidenceMode":"conservative","auto.insertOnNewline":true}

Help & troubleshooting

Questions? Start here.

Auto isn't inserting semicolons.

Run Auto: Show Status, confirm Auto is enabled, and check that your language is supported and not listed in auto.disabledLanguages. If needed, try Balanced mode and enable auto.debugLogging to inspect the Output channel.

Auto inserts semicolons where I don't want them.

Use "conservative" for auto.confidenceMode, or exclude the affected language through auto.disabledLanguages. Report a reproducible example on GitHub Issues ↗.

Does Auto send my code anywhere?

According to the extension's stated privacy design, editing is processed locally with no network requests, telemetry, analytics, AI inference, or external services. See the project repository and its PRIVACY.md for details.

Why are Go and Swift disabled?

Go uses lexical semicolon insertion, while Swift generally doesn't require semicolons. Auto disables these languages by default to avoid fighting their normal language behavior.

Are all code patterns guaranteed to work?

No. JavaScript and TypeScript have automatic semicolon insertion rules; Rust expressions can be valid without semicolons; and complex macros, C++ templates, or nested strings can be difficult to classify. Auto uses confidence thresholds to reduce mistakes, not eliminate every edge case.

Where can I report a bug or contribute?

Report issues at GitHub Issues, join Discussions, and see DEVELOPMENT.md, CONTRIBUTING.md, and SECURITY.md in the repository.
